# 公开文件范围与证据边界

本仓库公开集合以 Git 实际跟踪文件为准。发布前未提交阶段用 `git ls-files --others --exclude-standard` 查看候选，提交后用 `git ls-files` 生成打包清单；不要递归打包整个工作目录。源码、测试、声明的依赖、文档和小型示例属于候选。模型权重、虚拟环境、缓存、`.env`/令牌/私钥、`runs/`、原始私有材料及 `.git/` 不属于发布内容。Git 忽略只防止误收录，不能替代实际打包清单和最终扫描。

`PUBLICATION_MANIFEST.json` 逐项列出本轮角色42更改/删除的路径、原始 SHA-256、公开副本 SHA-256 和变换原因。这里的 SHA 记录的是该次变换时点，后续 UI/作者修改应由最终 Git HEAD 与交付清单补充验真。公开文件中的 `_publication` 标记说明它是经过脱敏的衍生记录：作者 home 路径替换为 `<AUTHOR_HOME>`，这个符号是解释性占位符，不能直接作为命令运行。原始字节另存于非发布工作区，不随仓库或学习包分发。

历史执行计数、失败、判定、耗时仍保留；脱敏不构成重跑。历史代码/输入摘要描述当时的对象，不能自动解释为当前源码或已裁剪运行目录的摘要。当前 `result.json` 的 `artifacts` 列表只绑定实际随包提供的公开文件。未修改的程序图形、真实推理输出、数据来源和许可仍遵守各自数据卡，不把模型输出重新授权为 MIT/CC0。

发布复查需同时检查：实际 Git 清单与归档成员、路径/邮箱/凭据样式、PNG/JPEG 元数据、所有声明 SHA、关键 HTML/日志链接。文本/元数据扫描不等于逐像素或逐帧隐私识别；许可清权也不由此证明。后续角色36–50报告、教程复制、最终 PDF/HTML 和 ZIP 均须在最后一次编辑后重新检查。
